# Contribuer à learning-games

Merci de vouloir aider. Le projet cherche des jeux simples, joyeux et utilisables par le plus grand nombre d’enfants.

## Avant de commencer

- Ouvrez une issue pour les changements importants afin de discuter du besoin pédagogique et de l’interaction.
- Pour une correction courte, une pull request directe convient très bien.
- N’ajoutez aucun outil publicitaire, traceur, compte obligatoire ou collecte de données enfant.
- Privilégiez une consigne courte, de grandes cibles tactiles et une alternative au son ou à la couleur.

## Proposer un changement

1. Créez une branche depuis `main`.
2. Installez les dépendances avec `npm install`.
3. Développez avec `npm run dev`.
4. Exécutez `npm run check`.
5. Décrivez dans la pull request le besoin traité, les tests réalisés et, pour l’interface, joignez une capture.

Toute contribution est publiée sous la licence AGPL-3.0-only du projet. En soumettant du code, vous confirmez avoir le droit de le partager sous cette licence.

## Principes de conception

- L’enfant doit comprendre où toucher sans longue lecture.
- Une erreur invite à réessayer ; elle ne punit pas.
- Le jeu reste utilisable au clavier et avec les technologies d’assistance.
- Les animations respectent `prefers-reduced-motion`.
- L’expérience principale fonctionne sur un écran de 320 px de large.

Les échanges suivent notre [code de conduite](CODE_OF_CONDUCT.md).
