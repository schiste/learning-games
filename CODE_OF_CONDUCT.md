# Code de conduite

Nous voulons une communauté accueillante pour les familles, les enseignants, les designers et les développeurs de tous horizons.

Soyez respectueux, précis et bienveillant. Les critiques portent sur les idées et les résultats, jamais sur les personnes. Le harcèlement, les propos discriminatoires, l’intimidation et la publication d’informations privées ne sont pas tolérés.

Les mainteneurs peuvent modifier ou retirer tout contenu inapproprié et prendre les mesures nécessaires pour préserver un espace sûr. Pour signaler un problème de manière confidentielle, utilisez l’adresse de sécurité publiée dans le profil de l’organisation ou du propriétaire du dépôt.

Ce texte est inspiré du [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
